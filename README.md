## ✨ Key Features
- **Responsive Mobile-First Card Design**: Built with clean aesthetic inspired by modern digital business cards.
- **Quick Action Triggers**: Direct links for Phone Call, Email, WhatsApp chat, and Google Maps location.
- **One-Click Contact Save**: Generates and downloads a `.vcf` (vCard) file with complete contact information.
- **QR Code & Native Sharing**: Integrated QR code modal with native Web Share API and link copying.
- **Interactive Micro-actions**: Instant tap-to-copy for primary phone, alternate phone & email with animated toast feedback.
- **Direct Instagram Profile**: Connect directly to Midlaj's official Instagram profile.
- **Zero Framework Bloat**: Pure HTML5, modern CSS3, and Vanilla JavaScript.

## 🚀 Live Preview / Setup

```bash

```
