# midlaj-portfolio-card

Digital contact card and responsive profile for **Midlaj Palanagad** — Professional Event Planner and Technician based in Thamarassery, Kerala, India.

## ✨ Features
- **Responsive Mobile-First Card Design**: Built with clean aesthetic inspired by modern digital business cards.
- **Quick Action Triggers**: Direct links for Phone Call, Email, WhatsApp chat, and Google Maps location.
- **One-Click Contact Save**: Generates and downloads a `.vcf` (vCard) file with contact information.
- **QR Code & Native Sharing**: Integrated QR code modal with native Web Share API and link copying.
- **Interactive Micro-actions**: Instant tap-to-copy for phone & email with custom animated toast feedback.
- **Zero Framework Bloat**: Pure HTML5, modern CSS3, and Vanilla JavaScript.

## 🚀 Live Preview / Setup
Simply open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
